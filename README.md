# 📊 Data Cleaning and Exploratory Data Analysis Using MySQL

## 📌 Project Overview

This project focuses on using *MySQL to clean, transform, and explore raw datasets* to make them suitable for meaningful data analysis.

The project demonstrates how SQL can be used to identify data-quality issues, handle inconsistencies, organize information, and uncover useful patterns and trends through Exploratory Data Analysis (EDA).

## 🎯 Project Objectives

- Understand the structure and characteristics of a raw dataset.
- Identify and handle missing and NULL values.
- Detect and remove duplicate records.
- Standardize inconsistent data and formats.
- Perform exploratory analysis to identify patterns and trends.
- Extract meaningful insights using SQL queries.

## 🛠️ Tools and Technologies

| Tool | Purpose |
|---|---|
| MySQL | Data cleaning and analysis |
| MySQL Workbench | Writing and executing SQL queries |
| SQL | Data manipulation, transformation and exploration |

## 🔍 Project Workflow

### 1. Data Exploration

The initial dataset is examined to understand its structure, columns, data types, and overall data quality.

Key activities:
- Inspecting the dataset.
- Understanding column names and data types.
- Identifying potential inconsistencies.
- Examining the distribution of available data.

### 2. Data Cleaning

The raw data is examined and prepared for analysis.

Key activities:
- Identifying missing and NULL values.
- Checking for duplicate records.
- Handling inconsistent or incorrect values.
- Standardizing data formats.
- Correcting data types wherever required.

### 3. Exploratory Data Analysis (EDA)

SQL queries are used to explore the cleaned dataset and extract meaningful information.

Key techniques include:

- *Aggregate Functions:* COUNT(), SUM(), AVG(), MIN(), MAX()
- *Filtering:* WHERE, HAVING
- *Grouping:* GROUP BY
- *Sorting:* ORDER BY
- *Joins:* Combining information from multiple tables.
- *Subqueries:* Performing nested data analysis.
- *CTEs:* Organizing complex queries using Common Table Expressions.
- *Window Functions:* Performing advanced analytical operations.
